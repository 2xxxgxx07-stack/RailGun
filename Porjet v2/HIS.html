HospiCore

HospiCore is a comprehensive, multi-module enterprise platform designed to support core hospital operations including Patient Registration, OPD, IPD, Nursing, Pharmacy, Laboratory, Referrals, Billing, and Executive Dashboards — unifying the entire hospital information system under a consistent and intuitive interface.

Overview

HospiCore is an enterprise hospital information system designed to unify all core hospital operations under a single, consistent platform. The system covers the full patient lifecycle from registration through outpatient and inpatient care, nursing, pharmacy, laboratory, billing, and executive reporting. The project addresses the fragmented UX patterns and inconsistent UI across existing multi-module hospital systems, aiming to reduce clinical errors and operational inefficiency through a unified, role-based interface.

UX Process

The design process began with research across multiple hospital departments to understand how different roles interact with the hospital information system throughout the patient journey. Research revealed significant UX inconsistencies between modules and the cognitive load placed on users who must operate across different parts of the system simultaneously. These insights shaped a unified design system and role-based interface architecture that was developed through wireframes and high-fidelity prototypes tested with clinical staff across departments.

Solution & Concept

HospiCore addresses the enterprise HIS challenge by establishing a unified design system and consistent interaction patterns across all modules. Each department's interface is tailored to its specific workflow while sharing the same navigation structure, component library, and data presentation conventions. The concept centers on Unified Experience, Role-Based Access, Cross-Module Data Continuity, and Scalable Architecture to support growing hospital operations without fragmenting the user experience.

Design thinking

Empathize

Research involved engaging with staff across Registration, OPD, IPD, Nursing, Pharmacy, and Laboratory departments to understand how each role uses the hospital system and where friction occurs. Users across all departments described navigating between system modules with different UI conventions, learning multiple interaction patterns for similar tasks, and dealing with data that did not transfer seamlessly between departments. User Personas were developed for key clinical and administrative roles. Empathy Maps captured the frustration of working within a fragmented enterprise system under time constraints and the impact on care quality and operational efficiency.

Define

Three primary challenges were defined: enterprise hospital systems with fragmented modules and inconsistent UI patterns, complex clinical workflows requiring management of massive datasets under strict time constraints, and poor data hierarchy with unclear system feedback increasing clinical error risk. Problem Statements and Design Goals were established to guide the solution toward a unified interface that maintains consistency across all modules while supporting each department's specific workflow. User Journey Maps traced patient pathways across multiple departments to identify data continuity requirements and inter-departmental workflow dependencies.

Ideate

Ideation focused on how to create a unified platform architecture that supports the diverse needs of multiple hospital departments without creating a complex, difficult-to-navigate system. User Flows were developed for the core workflows of each department, identifying shared interaction patterns that could be standardized across the platform. A comprehensive Sitemap organized HospiCore's modules around the patient lifecycle, ensuring that information flowed naturally between departments as patients progressed through different stages of care. The design system architecture was established to ensure visual and functional consistency across all modules.

Prototype

Wireframes were developed for key screens across Registration, OPD, IPD Nursing, Pharmacy, Laboratory, and Billing modules to validate layout consistency and cross-module navigation. High-fidelity designs applied the HospiCore design system across all modules, demonstrating how shared components, navigation patterns, and data presentation conventions create a unified experience across a complex enterprise system. Interactive prototypes simulated cross-departmental patient workflows for usability testing with multi-role hospital teams.

Test

Usability testing was conducted across multiple department-specific scenarios with clinical and administrative staff from Registration, Nursing, Pharmacy, and Billing. Testing evaluated how effectively the unified interface reduced the learning curve for new modules, how well data transferred between departments, and whether the role-based interface surfaced the right information for each user's responsibilities. Feedback drove refinements to navigation clarity, data hierarchy, and cross-module information continuity.

Testing Result & Feedback

  • Reduced Module Learning Curve — Consistent navigation and component patterns allowed staff to use new modules faster than with the previous system.
  • Improved Data Continuity — Patient information transferred seamlessly between department modules, reducing duplicate data entry.
  • Clearer Information Hierarchy — Clinical staff confirmed that the redesigned data presentation reduced the time needed to locate critical patient information.
  • Consistent Cross-Module Experience — Users reported significantly less confusion when moving between different functional modules of HospiCore.

Design System

Design System

The HospiCore Design System is an enterprise-scale library that establishes visual and functional consistency across all hospital modules. It includes a comprehensive component library, role-based UI patterns, department-specific data display guidelines, and a scalable design token system that allows the platform to grow without fragmenting the user experience.

Mood and tone

HospiCore's visual direction is authoritative, structured, and reliable. As an enterprise system used across an entire hospital organization, the interface must communicate professionalism and clarity at every level. The design uses a structured layout with clear data hierarchy, consistent component patterns, and a neutral palette that supports long periods of focused clinical and administrative work.
